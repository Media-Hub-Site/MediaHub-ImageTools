# ✨ MediaHub — Image Tools (AI)

Herramientas de procesamiento de imágenes con Inteligencia Artificial. Parte del ecosistema **Media Hub**.

## Herramientas incluidas
- **Background Eraser**: Eliminación de fondos con IA (rembg + u2net)
- **Quality Enhancer**: Super Resolución 4x (Real-ESRGAN ncnn Vulkan)
- **Bulk Watermark**: Marca de agua masiva en imágenes y videos
